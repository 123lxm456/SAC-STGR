# 时空方法、对照与可支持的主张

当前所有性能结果待实验。主规范为 [实施方案](../../research_implementation_plan.md)；两份章节止于 3.4 且保留该节原文，扩展消融见 [实验协议](../experiment-protocol.md)。

| 研究主张 | 模型或数据机制 | 必要对照与检查 | 可支持的结论边界 |
|---|---|---|---|
| 同刻九 token 交互有用 | 一层四头空间 Transformer | M1 对 B0，并与近容量非注意力融合 C1 比较 | 只有同数据、同预算、跨种子增量才支持空间编码作用；B0 单独不足以排除容量因素 |
| 逐组历史保留有用 | 九个 token 位置分别进入共享时间 Encoder | M1 对空间后立即汇总的 C2 | 比较保留八组时序与早汇总，不能据此声称逐车交互 |
| 末步动作条件读出有用 | 自车 token 查询八组时间表示 | M1 对无交叉注意力读出 C3；固定状态改变候选动作做响应检查 | 动作敏感性是模型关联行为，不是未执行动作的因果避碰证据 |
| 近期偏置有用 | 时间注意力加固定偏置 | M1 对 A-B | 仅比较偏置的增量；偏置不是因果掩码 |
| 风险反馈改善决策 | 风险分数以 `-3p` 进入共享 SAC 奖励 | M1 对 S0、B0 和系统基线；独立测试流与多种子 | 只对所测 SUMO 场景的闭环安全效率成立 |
| 风险分数可作为概率 | 真实结局预测窗、自然比例测试与校准 | Brier、可靠性图、事件分母；删失和伪标签审计 | 未校准前只称风险分数 |
| 八组输入语义正确 | 非连续字段切片与相对组别旋转 | one-hot 切片、八组唯一性、历史组别一致性 | 共同输入修复不能归因于 M1 |
| 工程成本可控 | 九 token 空间层、九条短时间序列、读出 | 参数量、硬件、批量和逐车时延、优化次数 | 注意力分数数量不等于实际实时性能 |

若主模型只在训练集或伪安全标签上改善，或没有稳定的闭环收益，应缩小主张。源论文的逐参与者轨迹结论只是分轴设计动机，不是本项目风险性能证据。
