# P5 压缩读取与统一目录实现

状态：本地实现、服务器迁移与删除后目标复验均已完成。服务器原始在线流由 30 个无损压缩对象保存，旧运行的有效凭据移入最新运行的 `provenance/`。

新增 `scripts/p5_storage.py` 提供压缩原字节读取、哈希核验、逐行分析、旧路径映射及原严格数据 reader 的兼容入口。`scripts/consolidate_p5.py` 提供 prepare/verify/finalize；`scripts/migrate_p5_storage.sh` 在独立 shell 中串行执行。修改 P5 审计、进度复核、复用、导出与两个结构审计入口；模型、标签和训练 worker 未改。`.gitignore` 排除统一目录中的压缩对象及分析临时目录。

来源凭据和 source.tar.gz 均保留原字节，旧运行移入最新运行的 provenance。重复复制内容通过 Linux 硬链接避免再次占用空间，独有权重与结果保留。压缩索引覆盖原始流全部别名，支持原始路径及迁移后的 provenance 路径；不会把 gzip 文件的哈希当作原始数据哈希。导出回传包排除压缩原始流。

最终本机 [133 项回归](p5-storage-verified-unit-20261126.json)：129 通过、4 CUDA 跳过、0 失败/错误；[日志](p5-storage-verified-unit-20261126.log)。其中模拟完整迁移使用临时文件和替代审计/目标进程，只验证存储流程，不是 SUMO 或研究结果。其他专项覆盖来源链迁移、内容损坏、截断、路径越界、部分读取、临时展开清理、导出排除及未验证拒绝删除。

[静态检查](p5-storage-static-20261126.json) 13 项通过；42 份当前 scripts/tests Python 通过 3.7 语法解析；[历史证据检查](p5-storage-historical-20261126.json) 通过，本地未重读服务器 P4 原始流。服务器目标验收与删除后复验分别见 `p5-entry-runs/20261126T151329681554Z/` 和 `p5-entry-runs/20261126T152836160193Z/`：均为 133 项单测通过、无跳过，P0—P4 原始数据复审和结构检查通过。
