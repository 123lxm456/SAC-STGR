# 项目概览

- 类型：计算机与智能驾驶方向的研究生方法论文方案；P2 独立模型已实现；2026-11-20 P0/P1/P2 目标环境复验通过，P3 本地接入开始，尚无新模型独立性能结果。
- 场景：SUMO 无信号交叉口，多辆受控车共享 SAC 策略，每车依据自身 98 维观测选择纵向加速度。
- 实施环境：新方案的环境复核、代码修改、训练和实验均基于 Linux 系统与 NVIDIA GeForce RTX 4090 GPU；实际软件版本在 P0 锁定。
- 研究问题：在八组聚合车流观测和最近 10 步历史下，逐时刻组间交互及其逐组时间演化能否改善风险评分与闭环安全效率权衡。
- 主方法：同一风险器内先用九 token 空间 Transformer，再用按 token 位置共享的时间 Transformer，最后用自车条件交叉注意力读出风险。
- 证据边界：八组是车流统计，不是八辆可跟踪周车；Sigmoid 输出是分数，未经真实分布校准不能称碰撞概率；文档设计不等于模型实现。
- 章节结构：`chapters/03_methods_experiments.md` 为完整方法与实验设计，`chapters/03_methods_experiments_brief.md` 的 3.1–3.3 独立介绍当前方法；两份 3.4 均逐字保留既定原文。扩展实验细节见 `plan/experiment-protocol.md`。
- 保护范围：`references/` 完全只读；原源码作为事实依据，不是改动目标。`output/` 已由用户明确要求删除。
